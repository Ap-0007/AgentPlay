# Video notes

1. Call the mapped subtitle-summary tool before writing notes.
2. Separate subtitle evidence from inference; never invent missing visuals or speech.
3. Organize the result as a short overview, key points, and timestamped chapters when timestamps exist.
4. Use the user's interface language and keep the output concise.
